## 5. Tech Debt

### Phase 1: SDK Core
- **Screenshot capture** — Uses white placeholder (`canvas.fillRect`) instead of actual DOM capture. Requires `html2canvas` or similar. This is the most significant functional gap.

### Phase 2: Backend API
- **ConsoleEntry schema** — Has dual `args`/`message` fields. SDK sends `message` (string), backend originally expected `args` (list). Fixed by making both optional, but schema is wider than needed.

### Phase 3: Admin Panel
- **No real-time updates** — Relies on manual refresh or localStorage CustomEvent for status updates across tabs.

### Phase 4: Docker Deployment
- **Single worker** — Uvicorn runs with `--workers 1` due to slowapi in-memory rate limiter constraint. No horizontal scaling.
