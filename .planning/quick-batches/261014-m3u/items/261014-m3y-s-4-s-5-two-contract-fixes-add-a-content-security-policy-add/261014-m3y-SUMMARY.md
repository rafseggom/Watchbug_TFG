## Decisions Made

- **CSP inside `location /`, pair repeated verbatim there** — the inheritance trap is real: declaring `add_header` at the inner level detaches the enclosing level's directives. The server-level pair stays for `location /api/` (which declares none).
- **CSP is not declared at server level** — it would attach a second `Content-Security-Policy` to every proxied API response next to the blob route's `default-src 'none'; sandbox` (`apps/api/src/routes/incidents.ts`), and the config already fights header duplication via `proxy_hide_header`.
- **R-08 as `.transform()`, not `.refine()` rejection** — R-08's wording is *stripped on ingest* (a normalisation), so a host forwarding `location.href` is silently normalised rather than 400'd; the transform is idempotent so both ingest stages stay safe.
- **`.max()` before `.transform()`** — the published `maxLength` and the runtime bound describe the same wire value.
- **`io: 'input'` in the emitter** — required once a transform is present; stays Zod's own native emitter, no converter, no hand-editing of the artifact.
