    3. Wrap the body parse — stopthatslop finding 5: parse inside a try/catch and on failure `throw new ApiError('invalid-json', …)`. Never return a partially parsed value, never `catch {}`-swallow: the caller must always receive either data or a coded error.

    6. Replace `fetchIncidents()` with `fetchIncidents(opts?: { limit?: number; cursor?: string | null }): Promise<IncidentPage>` where `export const PAGE_SIZE = 50` and `export interface IncidentPage { rows: Incident[]; nextCursor: string | null }`:
       - URL: `/api/incidents?limit=${limit ?? PAGE_SIZE}`, appending `&cursor=${encodeURIComponent(cursor)}` only when `cursor` is a non-empty string (cursor is an opaque token: encoded on the wire, never rendered, never interpreted client-side).
       - **Tolerant body normalization (do not break the mocks):** if the parsed body is a bare array → `rows = body` as-is; else if it is an object with an array `rows` field → `rows = body.rows`; else → throw `ApiError('invalid-json')`. This keeps `route.fulfill({ body: '[]' })` working no matter which response shape m3w settles on.

    7. **e2e/ingest.spec.ts — the mocks must keep matching:** Playwright globs compile to a `^…$` regex over the FULL URL including the query string, so the current `'**/api/incidents'` literal would no longer match `/api/incidents?limit=50` — both P1-D-07 rows would fall through to the real shared stack (never empty) and fail.
