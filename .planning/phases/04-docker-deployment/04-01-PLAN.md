<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client->api | Ingest POST /api/incidents is public by API key; API hardening (XSS sanitize, rate limit, payload guard) must survive containerized deployment |
| host->container | Compose published ports expose api:8000 and db 127.0.0.1:5432 to host; host trusts but must not expose db publicly |
| image->registry | Base images pulled from Docker Hub official library; unpinned or tampered images break build or inject code |
| env->container | Secrets via .env / env_file injected at runtime; image must not bake secrets in layers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | Dockerfile / image layers | high | mitigate | Never bake JWT_SECRET or POSTGRES_PASSWORD; use ${VAR:-placeholder} + env_file .env; .dockerignore excludes .env from context; verify via docker history shows no secret, per SEC-04 D-04 |
| T-04-02 | Elevation of Privilege | Dockerfile USER | high | mitigate | Create non-root user app UID 10001, chown /app, USER app before ENTRYPOINT; prevents container escape as root; verify whoami != root in runtime |
| T-04-03 | Denial of Service | postgres:16-alpine pin | medium | mitigate | Pin to postgres:16-alpine per D-02/DEP-05 (not :latest), document digest pin refresh procedure; prevents major 16->17 volume format corruption; verify grep image tag |
| T-04-04 | Denial of Service | db startup race | medium | mitigate | pg_isready healthcheck interval 10s retries 5 start_period 20s + api depends_on condition service_healthy long syntax; composing waits until DB accepts connections; avoids asyncpg connection refused flake |
| T-04-05 | Information Disclosure | ports / CORS | medium | mitigate | db ports 127.0.0.1:5432:5432 loopback only not 5432:5432; api CORS_ORIGINS default https://localhost per D-04 never wildcard with credentials; ensure IngestCorsMiddleware still open for SDK but admin allowlist stays closed |
| T-04-06 | Denial of Service | --workers >1 with slowapi | medium | mitigate | docker-entrypoint.sh forces --workers 1 for slowapi in-memory limiter (Pitfall 6); document scaling via compose --scale + external LB not in-process workers; verify entrypoint contains --workers 1 |
| T-04-07 | Tampering | base images | medium | mitigate | Base images are official library postgres/python/node (1B+ pulls each per Package Legitimacy Audit, verdict OK); pin tags 16-alpine/3.12-slim/22-alpine, optionally pin digests via docker pull + inspect, no new npm/pypi packages in this phase |
| T-04-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package-legitimacy gate passes: no new external packages, only existing backend/pyproject.toml and panel/package.json (already audited); build uses npm ci + pip install --no-cache-dir from lockfiles |

</threat_model>
