## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator->compose | Operator copies .env.example to .env and edits secrets; compromised example leaks placeholder awareness |
| compose->api | env_file .env overrides compose environment placeholders; precedence must be understood to avoid placeholder JWT in prod |
| api->db | First volume init creates POSTGRES_USER/PASSWORD; subsequent restores rely on volume not env, password rotation requires explicit SQL |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-08 | Information Disclosure | .env.example / JWT_SECRET placeholder | high | mitigate | Placeholder is change-me-to-a-random-secret-at-least-32-chars with generation command secrets.token_urlsafe(32) documented in both .env.example and README; compose default is insecure placeholder that fails-secure if operator skips override, app warns when default still active (follow up in welcome log) per D-04 SEC-04 |
| T-04-09 | Denial of Service | docker compose down -v | high | mitigate | README volume lifecycle matrix explicitly warns down -v destroys pgdata (incidents/users), operator must use down without -v for restarts; also document POSTGRES_* init-only caveat and ALTER USER path to avoid unnecessary volume wipes; compose volume is named pgdata not anonymous to make ls/inspect obvious |
| T-04-10 | Information Disclosure | CORS_ORIGINS | medium | mitigate | .env.example and compose default to https://localhost per D-04, never * with allow_credentials True (Starlette ValueError); ingest open CORS handled by IngestCorsMiddleware not via wildcard allowlist, verified via config.py cors_origins_list split |
