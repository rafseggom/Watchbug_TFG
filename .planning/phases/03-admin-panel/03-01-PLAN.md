| localStorage watchbug_lang | Untrusted persisted language, must allowlist en/es only |

|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | textContent rendering (PAN-07) | high | mitigate | Every DOM insertion uses createElement + textContent/createTextNode, never innerHTML; url href set only after !/^javascript:/i test per RESEARCH Pattern 8; backend html.escape is primary gate |
| T-03-02 | Spoofing | Login form + credentials:include | high | mitigate | Validate non-empty email/password client side (allow .local per D-08); apiFetch hard-codes credentials:include; login error is generic "Invalid credentials" inline + toast, no user enumeration via different messages |

| T-03-SC | Tampering | npm package installs | high | mitigate | Only vite/typescript/vitest/jsdom verified via npm view (RESEARCH Package Legitimacy Audit); no new runtime deps, no postinstall scripts |
