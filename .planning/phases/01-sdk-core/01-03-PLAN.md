       - Export function createMaskRectTool(ctx: CanvasRenderingContext2D): Tool
       - Mask Rect tool per D-09: onPointerDown records start point. onPointerMove draws a preview rectangle (dashed border). onPointerUp finalizes the mask.
       - Finalize: get the rectangle bounds, call maskRegion(ctx, x, y, width, height) to destructively modify pixels.
       - Export function createMaskPaintTool(ctx: CanvasRenderingContext2D): Tool
       - Mask Paint tool per D-09: onPointerDown starts recording points. onPointerMove adds points and applies maskRegion at each point's radius. onPointerUp finalizes.
       - Export function maskRegion(ctx: CanvasRenderingContext2D, x: number, y: number, width: number, height: number, mode?: 'pixelate' | 'solid'): void
       - Per EDT-02 and RESEARCH Pattern 2:
         * const imageData = ctx.getImageData(x, y, width, height)
         * const data = imageData.data (Uint8ClampedArray)
         * Per EDT-03: pixels permanently altered — no CSS overlays.
         * mode 'pixelate': divide into 8x8 blocks, average each block's color, fill block with average.
         * mode 'solid' (default): replace all pixels with opaque gray (128, 128, 128, 255).
         * ctx.putImageData(imageData, x, y) — CRITICAL: this writes permanently to canvas.
       - Per D-09: both rectangle brush and freehand paint available.
