## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SDK → Host Page | SDK is injected into host page; must not leak state or styles outward |
| Host Page → SDK | Host CSS/JS must not break or access SDK internals |
| Widget → User | Widget renders UI to user; must be accessible and functional |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | Shadow DOM | high | mitigate | Use mode: 'closed' — shadowRoot returns null from outside (INV-01) |
| T-01-02 | Information Disclosure | Global namespace | medium | mitigate | Single window.Watchbug entry point with only init/setConsent/getConsoleLogs (INV-02) |
| T-01-03 | Elevation of Privilege | Widget styles | medium | mitigate | All CSS scoped via adoptedStyleSheets on Shadow DOM root — no global style injection (RNF-02) |
| T-01-04 | Tampering | Host CSS | medium | accept | Host CSS cannot penetrate closed Shadow DOM — inherent browser guarantee; no additional mitigation needed |
</threat_model>
