## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SDK → Backend API | HTTP requests must not leak host credentials |
| Host App → SDK Consent | Developer controls capture via setConsent; must be honored |
| Draft Storage → User | localStorage contains report drafts; must not contain raw secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | fetch credentials | critical | mitigate | All fetch calls use credentials: 'omit' — never sends host cookies/tokens (SDK-05, SEC-03) |
| T-04-02 | Tampering | Consent bypass | high | mitigate | setConsent(false) stops all capture at source — console interception, onerror, batcher enqueue |
| T-04-03 | Information Disclosure | Draft storage | medium | mitigate | Drafts stored in localStorage — may contain screenshot data; document that drafts are local-only |
| T-04-04 | Denial of Service | Retry storm | low | mitigate | Exponential backoff with max 3 retries prevents unbounded retry loops |
| T-04-05 | Information Disclosure | Payload validation | medium | mitigate | Client-side validation rejects malformed payloads before network transmission |
</threat_model>
