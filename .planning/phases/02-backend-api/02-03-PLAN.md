<objective>
Harden the public ingest endpoint to production security: XSS sanitization before storage, 100KB payload guard (413 vs 422 split), split CORS (allowlist admin vs open ingest with null rejection), and slowapi in-memory rate limiting per IP + per project key with Retry-After. Completes SEC-01..04 and finishes API-02 ingest contract.

Purpose: Public ingest is the largest attack surface (any Origin can POST). Without these gates, DoS via large payloads, XSS via consoleLogs, CORS bypass via null, and flood abuse are viable.
Output: Hardened POST /api/incidents that correctly returns 401 vs 413 vs 422 vs 429, sanitizes before JSONB, handles both key headers and chunked bodies, and passes CORS/rate-limit tests.
</objective>
