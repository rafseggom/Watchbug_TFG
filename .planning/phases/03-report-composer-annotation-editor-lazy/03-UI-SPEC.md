# Phase 3 — UI Design Contract

> Visual and interaction contract for the SDK widget's report composer, lazy annotation
> editor, and review screen — all inside the closed Shadow DOM.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope of this Contract

This phase has **five UI surfaces**, all rendered inside the widget's closed Shadow DOM
(only surface: `packages/sdk`; the lazy editor is a **separate ≤ 25 KB gz entry point**,
loaded on demand):

1. **Floating launcher button** (unchanged, Phase 2 — the gesture entry).
2. **Floating status panel** (Phase 2) — now **reserved for in-flight + terminal send states
   only** (`Capturing…` / `Sending…` / `Retrying…` / `Report sent ✓` / failures); it is no
   longer the composition surface (P3-D-04).
3. **Report composer** (new, P3-D-01…04) — the large near-fullscreen overlay that **replaces**
   the Phase 2 one-shot shortcut: capture-then-form, editable auto-filled title, bug/feedback
   segmented toggle, note, image preview (the gateway to annotation), attach.
4. **Annotation editor** (new, lazy, P3-D-05…12) — fullscreen canvas editor: vertical icon
   toolbar (freehand / arrow / rectangle / text / mask) + undo, single accent ink, destructive
   opaque mask, `Done`.
5. **Review screen** (new, P3-D-16 / PRV-07) — the explicit "this is what will be sent" moment:
   final flattened image + summary + `Edit` / `Send report`.

**Not covered here (locked out of Phase 3):** console-log capture, environment metadata and
identity privacy (ENR-01…05, INT-03/04 → Phase 4); `apps/panel` (React) surfaces (Phase 5/6);
the IndexedDB durability lane (ING-02 → Phase 7). The server-side PNG+WebP **→ PNG+WebP+JPEG**
allowlist expansion (P3-D-14) is a security-surface change the **planner** owns, not this UI
contract.

**Governing hard constraints (non-negotiable):** INV-01 (closed Shadow DOM, zero host leakage),
INV-02 (one global `window.Watchbug`), RNF-01/PRF-01/PRF-04 (≤ 45 KB gz core, **zero runtime npm
dependencies**), PRF-02/PRF-03 (editor chunk ≤ 25 KB gz, total runtime ≤ 80 KB gz), RNF-02 (host
CSS cannot break the widget), R-13/A-01 (flat opaque α=255 fill is the only automatic primitive;
pixelation opt-in ≥ 8 px; **no gaussian blur, no CSS overlays**), C-2 (one flattened bitmap, masks
baked destructively at T2 and non-undoable, single `toBlob` sink), T-02-01/SEC-05 (no HTML sink —
text via `textContent`/`createElementNS` only), px-only units (H-2/H-3 — zero `rem`/`em`).

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — forbidden by PRF-04 (zero runtime deps) and RNF-01 (45 KB gz budget) |
| Icon library | none — hand-rolled inline SVG via `createElementNS`, zero image/font assets |
| Font | `system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif` (unchanged; no webfont — impossible under isolation + budget) |

**Why `Tool: none` is correct here, not a gap:** the widget is vanilla TypeScript rendered through
`WidgetHost` into a closed shadow root. shadcn/Radix are React packages and would consume the entire
budget and violate PRF-04. The lazy editor is hand-rolled canvas + DOM. All CSS is hand-written
inside the shadow root's single `<style>` element, concatenated alongside `HOST_CSS` (Phase 2).

**shadcn gate:** not applicable — no React surface is in scope and no `components.json` exists.
**Registry vetting gate:** not applicable — no registries are consumed.

## Typography

Exactly **4 sizes**, exactly **2 weights**. All px; declared on the shadow `.wrap` (the
`all: initial` reset strips inherited font — every used property is re-declared).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label (hints, field labels, toolbar aria, secondary actions, toggle) | 13px | 400 (600 on buttons) | 1.4 |
| Body (input values, note, review summary, editor hints) | 15px | 400 (600 for emphasis) | 1.5 |
| Heading (composer header, review header, editor top-bar title) | 19px | 600 | 1.2 |
| Display (mask-confirmation headline — the irreversibility moment) | 24px | 600 | 1.2 |

- Weights: **400** (default) and **600** (headings, button labels, active segments) — never more.
- Font family: `system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif` (re-declared on `.wrap`).
- No webfonts, no `@font-face`, no external font requests (size budget + H-8 neutrality).
- Canvas annotation text labels render at **15px** (Body) in accent ink (P3-D-07 single-color ink).
- Text color inherits from `.wrap` (`#1b1f26`); never `currentColor` from the host.

## Color

Palette values mirror the locked Phase 1/2 token set (light values), re-declared locally as
`--wb-*` custom properties inside the shadow root. Single fixed light palette (no dark variant).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` | Composer, editor, review and dialog surfaces |
| Secondary (30%) | `#eef0f4` (surface-alt) + `#d6dae1` (border) | Form field fills, canvas backdrop, toolbar rail, secondary buttons, toggle track, 1 px borders |
| Accent (10%) | `#2f6feb` | See "Accent reserved for" below |
| Destructive | `#b3261e` | Inline validation/attachment error text + discard `✕` glyph (hover) |

Supporting inks (text only, not part of the 60/30/10 split):
- Body ink `#1b1f26` (on `#ffffff`: ≥ 12:1), muted ink `#5b6472` for hints (≥ 4.5:1 — AA).
- Success `#1e7a46` (`✓` glyph), on-accent `#ffffff`.
- Hover `#2962cf`, active/pressed `#2456b8` (precomputed darker accent; no `filter`).
- **Mask fill (canvas, new): `rgb(0,0,0)` α=255** — flat opaque black, matching the Phase 2 T1
  auto-redaction fill (`MASK_RGB = {r:0,g:0,b:0}` in `redactor.ts:44`) **exactly**. The user mask
  must read as the *same* redaction the auto-mask already applies. Pixelation mode has no fixed
  color (block average of source pixels).

**Accent reserved for (enumerable, never "all interactive elements"):**
1. The launcher button fill (inherited, Phase 2).
2. The single annotation ink color — freehand strokes, arrows, rectangle outlines, text labels
   (P3-D-07: "tinta de un solo color"; zero color-picker UI).
3. The active annotation tool's button fill in the toolbar (unselected tools = surface-alt + ink
   glyph).
4. The active segment of the bug/feedback toggle.
5. The one filled primary CTA per screen — composer **"Review report"**, editor **"Done"**, review
   **"Send report"**, mask dialog **"Mask"**.
6. Focus rings (2 px solid, 2 px offset).
7. The in-flight spinner arc (inherited).

Secondary actions (`Edit`, `Attach image`, `Replace`, `Not now`, `Dismiss`) are **never** accent —
they are `surface-alt` fill + ink text + 1 px border.

**Destructive reserved for:** inline form-validation error text (empty required title),
attachment-rejection error text, and the composer/review discard `✕` glyph on hover. There are
**no filled destructive buttons** in this phase — masking is privacy-protective, not destructive,
so the mask confirmation's primary button is accent, not danger.

Every color is a `--wb-*` property on the shadow wrapper (or an RGBA canvas constant for the mask)
— zero hardcoded colors in component code, zero host-inherited color.

## Widget Geometry & Layout

All fixed, px-only, inside the shadow root (host-element inline `!important` contract unchanged from
Phase 2 — launcher + host anchoring preserved).

- **Composer overlay** (P3-D-04 "large near-fullscreen"): `position: fixed; left:50%; top:50%;
  transform: translate(-50%,-50%); width: min(720px, calc(100vw - 32px));
  max-height: min(90vh, calc(100vh - 32px));` radius 8 px; `#ffffff` on `1px solid #d6dae1`;
  elevation `0 8px 24px rgba(27,31,38,0.18)`; padding 16 px; internal sections stack at 16/24 px;
  content area scrolls (`overflow-y: auto`) if it exceeds `max-height`.
- **Editor overlay** (P3-D-05 fullscreen): `position: fixed; inset: 0;` surface `#ffffff`; **top bar
  56 px** (title + hint left, `Done` right, `1px solid #d6dae1` bottom border); **left toolbar rail
  56 px** (`1px solid #d6dae1` right border); canvas area fills the remainder, backdrop
  `#eef0f4`, image "contain"-fit centered with a `1px solid #d6dae1` border.
- **Review overlay**: same frame as the composer overlay (`min(720px, …)`, 90 vh, radius 8 px,
  elevation), header + large flattened image + summary block + footer.
- **Mask confirmation dialog** (P3-D-09): `width: min(360px, calc(100vw - 32px))`, centered on the
  editor, radius 8 px, surface, elevation, padding 16 px.
- **Toolbar**: 5 tool buttons stacked at 8 px gap, then a 1 px `#d6dae1` divider (16 px margin),
  then **undo**; each button 44×44 px radius 6 px.
- **Segmented toggle**: full-width in the composer, 36 px tall, radius 6 px, track `surface-alt` +
  border; active segment = accent fill + on-accent text; inactive = transparent + ink text.

## Interaction & State Contract

### Flow (capture-then-form — P3-D-01)

```
launcher click → capture (transient activation preserved)
  ├─ success → composer (image present)         → [Annotate] → editor → [Done] → composer
  └─ failure → composer (degraded, CAP-03)      → [Review report] → review → [Send report] → status
        ├─ [Attach image] → file picker (PNG/WebP/JPEG) → composer (image present)
        └─ [Continue with text only] → composer (text-only, no image zone)
```

### View states

| View | Trigger | Visible UI | Exits |
|------|---------|------------|-------|
| `launcher` | init / after terminal dismiss | launcher only | click → capture → composer |
| `status.*` | in-flight send / terminal result | status panel (in-flight: spinner + copy; terminal: glyph + copy + buttons) | `sent` auto-dismiss 5 s / `Dismiss`; failure `Try again` / `Dismiss` (Phase 2 semantics unchanged) |
| `composer` | capture success **or** capture failure | overlay: header, toggle, title, note, image zone, footer | `✕`/`Escape` → discard → `launcher`; `Review report` → `review`; `Annotate` → `editor`; `Attach image` → file picker |
| `editor` | `Annotate` (lazy chunk loads) | fullscreen: top bar + toolbar + canvas | `Done` → `composer`; (no other exit while editing — see discard note) |
| `review` | `Review report` | overlay: final flattened image + summary + footer | `Edit` → `composer` (→ annotate); `Send report` → `status.sending`; `✕`/`Escape` → `composer` |
| `maskConfirm` | first mask drag-release of session (P3-D-09) | dialog over editor | `Mask` → apply, never re-ask this session; `Not now` → cancel mask |

**Re-entrancy:** launcher disabled while any overlay is open; exactly one overlay at a time.

### Annotation editor (P3-D-06…12)

- **One active tool at a time**; toolbar buttons are `aria-pressed` toggles. Default tool on open:
  **freehand**.
- **Freehand (ANN-01):** pointer drag → accent stroke, 3 px logical width (× DPR in bitmap space, H-1).
- **Arrow (ANN-02):** drag tail→head → 3 px accent line + filled arrowhead (~12 px length).
- **Rectangle (ANN-03):** drag corner→corner → 3 px accent outline, no fill.
- **Text (ANN-04):** click canvas → inline `<input>` (textContent-safe) at the anchor → type →
  `Enter` **or** click-outside confirms → accent 15 px label rendered on canvas. **No modal**.
- **Mask (ANN-05/PRV-04):** drag a rect → on release the region is **destructively** filled opaque
  black α=255 in the working `ImageData` (T2), baked immediately and **not undoable**. A
  **Fill / Pixelate** segmented mini-toggle appears (near the toolbar, mask tool active only);
  **Fill is default** (P3-D-10). Pixelate = block-average at block ≥ `max(8 px, 2×cap-height)`,
  grid-snapped outward, α=255. **First mask of the session** raises the confirmation dialog; later
  masks bake on release without re-confirming.
- **Undo (ANN-06):** toolbar button **and** `Ctrl/Cmd+Z`; removes one annotation stroke
  (freehand/arrow/rect/text) at a time, **never a mask**; stack capped at ~20 strokes (P3-D-11).
- **No "clear all annotations"** (P3-D-12). Masks persist.
- **Single `toBlob` sink:** `encodeFinal()` routes through the existing `encodeOnce` (C-2);
  export order is an invariant: flatten ink → re-bake masks **last** → re-run T1 → fresh `toBlob`.

### Lazy-load (PRF-02 — default, see Assumption A-2)

The editor chunk loads **on demand at the `Annotate` click**, not at capture. While it fetches, the
`Annotate` button shows an inline 12 px spinner + `Loading…` (13 px label) and is disabled; on
error the button re-enables with the attach-error style (never a dead state). Prefetch-on-capture
is rejected: it downloads editor bytes for reports that never annotate.

### Degraded composer (CAP-03 / P3-D-13)

Capture failure renders the composer **with the image zone in a notice state**, never a dead error
panel: a muted "Capture unavailable" heading + hint, and two inline actions **"Attach image"** and
**"Continue with text only"**. Both keep the user inside the composer. Text-only mode hides the
image zone and keeps a subtle `Attach image` affordance in the footer.

### Motion

- Composer/review/dialog entrance: `opacity 0→1` + `translateY(4px→0)`, 120 ms ease-out.
- Editor entrance: `opacity 0→1`, 120 ms ease-out (fullscreen, no translate).
- Mask fill application: **instant, no animation** (destructive; must feel immediate and final).
- Stroke drawing and text labels: direct draw, no animation.
- `@media (prefers-reduced-motion: reduce)`: all entrances removed, spinner static (CSS-only).
- No animation library, no JS timers for animation.

### Accessibility

- Every control is a real `<button>`/`<input>`/`<textarea>`; tool buttons have `aria-label` +
  `aria-pressed`; the toolbar is keyboard-navigable (Tab, arrow keys switch tools, Enter selects).
- Composer opens with focus on the title input; review opens with focus on `Edit`; mask dialog is
  `role="alertdialog" aria-modal="true"` with focus moved to `Mask` on open, `Escape` = `Not now`,
  focus returned to the mask tool button on close.
- `Escape`/`✕` discards the composer or review (returns to launcher) and closes the editor via
  `Done`; a single document-level `keydown` listener, removed on teardown (Phase 2 A-7 pattern).
- Visible `:focus-visible` ring 2 px `#2f6feb` / 2 px offset on every interactive element.
- All actionable hit targets ≥ 24×24 px (AA); toolbar and primary buttons ≥ 44 px / 48 px.
- Inline errors (empty title, rejected attachment) are `role="alert"` / `aria-describedby` on the
  field, announced without stealing focus.
- Canvas carries `role="img"` + `aria-label` (`editor.canvas.label`) and is pointer-primary; the
  text tool's Enter-to-confirm is the keyboard path for labels.
- The `.wrap` `lang` attribute reflects the resolved locale (`en`/`es`) — replaces the Phase 2
  `en` literal (F-08).

### i18n (WDG-06 — default, see Assumption A-1)

- Auto-detect `navigator.language` at init: `es*` → Spanish, else English.
- Manual override: a compact **EN/ES toggle in the composer header** (a small segmented pair,
  `aria-label` `i18n.label`), visible in the composer only.
- **Persistence (default): session-scoped in-memory** — the override applies for the current page
  session only and is re-detected on the next load. The `localStorage` persistence referenced in
  the discretion note (P1-D-05 panel pattern) is **not** applied to the widget because SEC-03's
  "never touch host storage" invariant and the `document.cookie|localStorage|sessionStorage|…` grep
  gate make host-origin storage off-limits for an injected third-party script. Flagged below (A-1).
- Dictionaries `strings` + `stringsEs` live in the **lazy chunk, never core**; the resolver is
  additive to `strings.ts`.
