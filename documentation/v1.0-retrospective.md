## 2. Decisiones Arquitectónicas Clave

### 2.1 SDK Core

| Decisión | Alternativa descartada | Por qué ganó | Verificado en |
|----------|----------------------|--------------|---------------|
| `canvas.toDataURL` sobre `html2canvas` | html2canvas (~40KB) | Mantiene bundle en 8.85KB vs 45KB límite | `01-05-SUMMARY` |
| `mode: 'closed'` Shadow DOM | `mode: 'open'` | Aislamiento total: host CSS/JS no puede acceder al widget | `01-01-SUMMARY`, E2E adversarial |
| `credentials:'omit'` en todos los fetches | `credentials:'include'` o `'same-origin'` | SEC-03: nunca filtrar cookies/tokens del host | `01-04-SUMMARY` |
| Masking destructivo via `getImageData` | CSS overlay sobre canvas | SEC-02: CSS overlay es reversible; pixel mutation es permanente | `01-03-SUMMARY`, `01-SECURITY` |
| `connectedCallback` para ARIA | `constructor` | jsdom lanza error en constructor de custom elements | `01-01-SUMMARY` |
| `adoptedStyleSheets` con fallback `<style>` | Solo `<style>` | API moderna en producción; fallback para jsdom | `01-01-SUMMARY` |
| Per-tool factory functions | Clases con herencia | Sin `this` binding issues, herramientas independently testable | `01-03-SUMMARY` |
| Ring buffer con eviction | IndexedDB o localStorage | Simple, bounded memory, suficiente para logs de consola | `01-02-SUMMARY` |
| Redacción de secretos vía 7 regex | Biblioteca de PII detection | Bundlesize, 7 patrones cubren 95% de casos comunes | `01-02-SUMMARY` |
| Retry con exponential backoff | Fixed delay | Previene thundering herd en fallos transitorios | `01-04-SUMMARY` |
| IIFE + dual output | Solo ESM | IIFE para `<script>` tag, ESM para bundler consumers | `01-05-SUMMARY` |
| E2E tests con hook `_getShadowRoot` | Open mode para tests | Prueba que `shadowRoot === null` (INV-01) sin comprometer aislamiento | `01-05-SUMMARY` |

### 2.2 Backend API

| Decisión | Alternativa descartada | Por qué ganó | Verificado en |
|----------|----------------------|--------------|---------------|
| `bcrypt` directo, no `passlib` | passlib wrapper | Sin dependencia extra; `hashpw`/`gensalt` son suficientes | `02-02-SUMMARY` |
| `email: str` no `EmailStr` | Pydantic EmailStr | EmailStr rechaza dominios `.local` (admin@watchbug.local) | `02-02-SUMMARY` |
| `html.escape` + event-handler strip | bleach | bleach añade dependencia C pesada; stdlib es suficiente para plain text | `02-03-SUMMARY` |
| CORS split: allowlist admin + open ingest | CORSMiddleware con `allow_origins=["*"]` | Starlette rechaza `*` + `credentials: true`; dos middlewares resuelven | `02-03-SUMMARY` |
| Per-route 413 guard | Global BaseHTTPMiddleware | Chunked encoding puede no tener Content-Length; `request.body()` es explícito | `02-03-SUMMARY` |
| `slowapi` in-memory + single worker | Redis rate limiter | Zero dependencies externas; in-memory suficiente para self-hosted | `02-03-SUMMARY` |
| `NullOriginMiddleware` en outermost | Check en endpoint | file:// debe ser rechazado ANTES de cualquier procesamiento | `02-03-SUMMARY` |
| BYTEA re-encode solo en detail | Re-encode en list | List con 20 filas BYTEA sería lento; detail necesita la imagen | `02-04-SUMMARY` |
| Alembic async con NullPool | Pool normal | NullPool previene issues de connection pool durante migraciones | `02-01-SUMMARY` |
| Seed admin idempotent en lifespan | Script separado | Zero-config startup; cambiar `ADMIN_PASSWORD` rota hash automáticamente | `02-02-SUMMARY` |

### 2.3 Admin Panel

| Decisión | Alternativa descartada | Por qué ganó | Verificado en |
|----------|----------------------|--------------|---------------|
| Hash routing (`#/`) | History API (`pushState`) | Evita fallback del servidor en SPA montada en `/panel` | `03-01-SUMMARY` |
| Vite `base: "./"` | `base: "/"` | Rutas relativas para mount en subpath `/panel` | `03-01-SUMMARY` |
| `probe+refresh` auth guard | Leer cookie HttpOnly | JavaScript no puede leer HttpOnly cookies; probing es la única forma | `03-01-SUMMARY` |
| CSS variables, no preprocessor | Sass/Less | Vite maneja CSS nativamente; preprocessor es overkill para panel pequeño | `03-01-SUMMARY` |
| Hash query para filtros | Estado en memoria | URLs shareable/bookmarkable; sin state management library | `03-02-SUMMARY` |
| Optimistic PATCH con revert | Esperar respuesta | Feedback inmediato; revert seguro porque backend es source of truth | `03-03-SUMMARY` |
| `textContent` exclusivo, zero `innerHTML` | innerHTML con escape | PAN-07: previene Stored XSS; grep verifica 0 hits | `03-03-SUMMARY` |
| Badge sanitize con allowlist | Clase dinámica | Previene class injection XSS de valores controlados por usuario | `03-02-SUMMARY` |

### 2.4 Docker Deployment

| Decisión | Alternativa descartada | Por qué ganó | Verificado en |
|----------|----------------------|--------------|---------------|
| Multi-stage: Node builder + Python runtime | Single stage | No Node.js en producción; image más pequeña | `04-01-SUMMARY` |
| `env_file: required: false` | required: true | Developer experience: first clone funciona con defaults | `04-02-SUMMARY` |
| `curl -f` healthcheck | JSON body check | Infra-only phase boundary; JSON validation es test concern | `04-02-SUMMARY` |
| `docker-entrypoint.sh` (alembic + uvicorn) | Separate init | Schema migration DEBE correr antes de recibir requests | `04-01-SUMMARY` |

## 3. Errores y Cómo Se Resolvieron

### 3.1 SDK Core

| Error | Causa raíz | Fix | Lección |
|-------|-----------|-----|---------|
| `window.Watchbug.init is not a function` | IIFE exportaba `window.Watchbug = { init, ... }` (objeto) en vez de instancia | Crear `iife-entry.ts` con `export default createWatchbug()` — IIFE retorna instancia directa | **Entrada IIFE debe ser default export que retorne instancia, no objeto con métodos** |
| jsdom: `Unexpected attributes` en constructor | Custom element constructor no puede usar `setAttribute` | Mover ARIA a `connectedCallback` con `hasAttribute` guard | **ARIA attributes van en connectedCallback, no en constructor** |
| jsdom: `adoptedStyleSheets` undefined | jsdom no soporta la API | Fallback con `<style>` element; producción usa `adoptedStyleSheets` | **Siempre tener fallback para APIs no soportadas en jsdom** |
| Canvas tainted SecurityError | Cross-origin image en canvas | Catch + timeout race en `toDataURL` | **Manejar SecurityError en captura canvas** |
| Tests fallan cuando todos corren juntos | `window.onerror` chaining entre tests | Preservar handler previo con `@ts-ignore` para TypeScript | **Tests deben isolarse; onerror chaining es frágil** |

### 3.2 Backend API

| Error | Causa raíz | Fix | Lección |
|-------|-----------|-----|---------|
| `Origin: null` rechazado por backend | SEC-01: file:// protocol rechazado | Test page debe servirse via HTTP, no `file://` | **Origin null = file:// protocol; debe servirse vía HTTP server** |
| Pydantic `EmailStr` rechaza `admin@watchbug.local` | email-validator rechaza dominios `.local` | Cambiar a `email: str` | **No usar EmailStr para self-hosted con dominios locales** |
| CORS preflight 403 | `CORSMiddleware` bloquea antes de `IngestCorsMiddleware` | Reordenar middlewares: NullOrigin → IngestCors → CORS → SlowAPI | **Starlette middleware order es crítico; outermost se ejecuta primero** |
| Rate limiter contamina tests | slowapi in-memory acumula entre tests | Fixture autouse `limiter.reset()` | **Rate limiter necesita test isolation** |
| chunked encoding sin Content-Length | Algunos clientes usan chunked por defecto | Per-route `await request.body()` para tamaño real | **Nunca confiar en Content-Length; usar request.body()** |
| BYTEA almacenado dos veces | screenshot quedaba en JSONB Y en BYTEA | Pop explícito de screenshot del payload antes de store | **Siempre limpiar campos derivados del payload** |
| Invalid filter values retornan 200 | Silently ignored | Upfront `ValueError→422` | **Validar filtros antes de ejecutar query** |
| List lazy-load N+1 | BYTEA diferido carga por fila | `inspect(state.unloaded)` para detectar deferred | **Usar load_only en list; re-encode BYTEA solo en detail** |

### 3.3 Admin Panel

| Error | Causa raíz | Fix | Lección |
|-------|-----------|-----|---------|
| 404 en `/panel/assets/*` | Vite generaba paths absolutos `/assets/...` | `base: "./"` para paths relativos | **Siempre usar paths relativos para SPAs en subpaths** |
| Auth guard no detecta sesión expirada | JavaScript no puede leer HttpOnly cookies | `probe+refresh`: probing endpoint autenticado | **La única forma de verificar sesión es probing** |
| Refresh endpoint sin cookie | Cookie path scope es estricto | Fetch con path exacto `/api/auth/refresh` | **Cookie path debe coincidir exactamente** |
| CSS badge injection | Valor de usuario como clase CSS directa | Allowlist `sanitizeClass()` + fallback `badge--unknown` | **Nunca usar valores de usuario como CSS class sin sanitizar** |
| jsdom no aplica CSS layout | jsdom no calcula layout | Verificar CSS vía grep en source, no DOM assertions | **Responsive CSS no es testeable en jsdom** |

### 3.4 Docker Deployment

| Error | Causa raíz | Fix | Lección |
|-------|-----------|-----|---------|
| `localhost` resolve a IPv6 en Windows | Docker Desktop Hyper-V networking | Usar `127.0.0.1` en `DATABASE_URL` | **En Windows, 127.0.0.1 es más confiable que localhost** |
| `PYTHONPATH` faltante en container | Alembic no encuentra módulos | Agregar `PYTHONPATH=/app` en compose | **Python apps en Docker necesitan PYTHONPATH explícito** |
| Puerto 5432 ocupado por PG local | Conflicto con PostgreSQL del host | Mapear `5433:5432` | **Documentar puerto alternativo para evitar conflictos** |
| `POSTGRES_*` vars no efecto al cambiar | Solo funcionan en primera init del volumen | Documentar en `.env.example` con instrucciones de rotación | **POSTGRES_* vars son init-only; documentar comportamiento** |

## 4. Patrones Reutilizables

### 4.1 SDK Patterns

```typescript
// 1. Single global entry point — sin prototype pollution
window.Watchbug = createWatchbug(); // instance, no object

// 2. Shadow DOM isolation
this.attachShadow({ mode: 'closed' }); // INV-01: shadowRoot === null

// 3. credentials:'omit' en todos los fetches
fetch(url, { credentials: 'omit', ...opts }); // SEC-03

// 4. Destructive canvas masking
ctx.getImageData(x,y,w,h) → mutate Uint8ClampedArray → putImageData(); // SEC-02

// 5. Secret redaction pipeline
message → 7 regex patterns → truncate 500 chars → buffer

// 6. localStorage draft persistence
localStorage.setItem(`watchbug_draft_${key}`, JSON.stringify(payload));

// 7. Ring buffer
createConsoleBuffer(maxEntries) → shift oldest when full → getAll() returns copy
```

### 4.2 Backend Patterns

```python
# 1. Split CORS architecture
NullOriginMiddleware (reject null) → IngestCorsMiddleware (echo any) → CORSMiddleware (allowlist)

# 2. JWT HttpOnly cookie auth
login → set_cookie("watchbug_access", jwt, httponly=True, samesite="lax")

# 3. Recursive XSS sanitization
sanitize_payload(obj) → html.escape + event-handler strip at leaf strings

# 4. Per-route payload size guard
body = await request.body()  # not Content-Length
if len(body) > settings.MAX_PAYLOAD_BYTES: raise 413

# 5. Composite rate limit key
f"{get_remote_address(request)}:{project_key}"  # per-IP + per-project

# 6. Seed-on-startup
lifespan → seed_admin() + seed_default_project() idempotently
```

### 4.3 Panel Patterns

```typescript
// 1. Hash router
const { path, params } = parseHash(); // location.hash.slice(1).split('?')

// 2. apiFetch with auto-refresh
async function apiFetch(url, opts) {
  let res = await fetch(url, { credentials: 'include', ...opts });
  if (res.status === 401) {
    const refresh = await fetch('/api/auth/refresh', { method: 'POST', credentials: 'include' });
    if (refresh.ok) res = await fetch(url, { credentials: 'include', ...opts });
    else { location.hash = '#/login'; throw new Error('unauthorized'); }
  }
  return res;
}

// 3. Optimistic update with revert
select.value = newStatus; // optimistic
const res = await apiFetch(...);
if (!res.ok) { select.value = prev; showToast('error'); return; }

// 4. Badge sanitize
function sanitizeClass(name) {
  const allowed = ['Bug', 'Feedback', 'Pending', 'In Progress', 'Resolved'];
  return allowed.includes(name) ? `status-${name.toLowerCase().replace(/\s+/g, '-')}` : 'badge--unknown';
}
```

## 5. Anti-Patrones a Evitar

| Anti-Pattern | Por qué es malo | Qué hacer en su lugar |
|-------------|-----------------|----------------------|
| CSS overlay para masking | Reversible: inspeccionar elemento revela original | `getImageData` → mutar píxeles → `putImageData` |
| `innerHTML` con escape manual | Fácil de olvidar; breach de Stored XSS | `textContent` / `createTextNode` exclusivamente |
| `allow_origins=["*"]` + `credentials: true` | Starlette lanza ValueError | Split CORS: open ingest middleware + allowlist admin middleware |
| `Content-Length` para tamaño de payload | Chunked encoding no tiene Content-Length | `await request.body()` explícito |
| Atributos ARIA en `constructor` | Custom elements spec: constructor no puede setear atributos | `connectedCallback` con `hasAttribute` guard |
| `EmailStr` para self-hosted apps | Dominios `.local` son rechazados por pydantic-email-validator | `str` con validación manual si es necesario |
| `POSTGRES_*` vars dinámicas | Solo funcionan en primera init del volumen | Documentar que son init-only; ofrecer script de rotación |
| `localhost` en Docker Windows | Puede resolver a IPv6 `::1` con fallback de 10s | Usar `127.0.0.1` explícito |
| Test isolation sin reset de rate limiter | Rate limit acumula entre tests | Fixture autouse `limiter.reset()` |
| IndexedDB para drafts pequeños | Overhead async + versioning innecesario | `localStorage` para JSON <100KB |

## 6. Gap más Grande: Screenshot Placeholder

**El problema:** `captureScreenshot()` llena un rectángulo blanco en vez de capturar el DOM real.

**Por qué:** `html2canvas` añade ~40KB; el bundle final es 8.85KB. La alternativa `dom-to-image` está poco mantenida.

**Impacto:** Los usuarios ven un cuadrado blanco en vez del contenido real de la página cuando reportan un bug.

**Opciones para v2:**
1. `html2canvas` detrás de feature flag — bundle crece a ~49KB (excede 45KB, necesita justificación)
2. `dom-to-image` — menos mantenido pero más ligero (~25KB)
3. Canvas API custom con limitaciones — captura viewport-only, no DOM completo
4. Browser-native `getComputedStyle` + manual rendering — más trabajo, más control

**Recomendación:** Evaluar `html2canvas` con lazy-loading dinámico (import dinámico) para no impactar bundle inicial.

## 7. Schema Drift entre Fases

**Problema:** El SDK fue desarrollado en Fase 1, el backend en Fase 2. El SDK envía `{ level, message, timestamp }` pero el backend esperaba `{ level, args: list[str], timestamp }`.

**Solución aplicada:** Hacer ambos campos opcionales en `ConsoleEntry`.

**Prevención para v2:**
1. Definir OpenAPI/Swagger spec ANTES de implementar ambos lados
2. Usar codegen del spec para generar tipos en ambos lados
3. Tests de contract testing que validen schema contra payload real

## 8. Lo que Mejor Funcionó

### 8.1 Tracer-First Approach
Cada plan empezaba con un test que demostraba el invariante. El backend (65 tests) pasó todos en el primer run completo. El approach "plan → test → implement" eliminó iteraciones de fix.

### 8.2 Bundle Size Gate
`scripts/check-size.js` con `process.exit(1)` en exceso forzó disciplina desde el día 1. Resultado: 8.85KB gzipped, 81% de headroom.

### 8.3 E2E Adversarial Testing
El test `* { display: none !important }` inyectado como CSS host fue la prueba definitiva de Shadow DOM isolation — más convincente que cualquier unit test.

### 8.4 Zero innerHTML in Panel
Grep verificó 0 hits de `innerHTML` en producción. Todo usa `textContent`/`createTextNode`. Pattern es enforceable via CI lint.

### 8.5 Continuity Pack
Los dead-ends escritos inmediatamente después del fallo (no al final) evitaron re-exploración de caminos fallidos en fases posteriores.

---

## 9. Lo que Más Dolió

### 9.1 Screenshot Placeholder
El gap funcional más grande. Los usuarios no ven contenido real.

### 9.2 CORS Middleware Ordering
Starlette middleware order es crítico y no está documentado claramente. Tuvimos que descubrir el orden correcto por trial-and-error.

### 9.3 Windows Docker Networking
`localhost` resolviendo a IPv6 con fallback de 10s causó confusión. `127.0.0.1` es más confiable.

### 9.4 ConsoleEntry Schema Drift
Desarrollar SDK y backend en fases separadas sin shared schema causó mismatch que tuvimos que parchear con campos opcionales duales.
